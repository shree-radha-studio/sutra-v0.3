# Sutra phone app kit

Three phones (390×844) side by side, each a live screen of the same app:
- **Catalogue** — lockup top bar, category tabs (maroon underline), filter chips, 2-up picture-first grid with glass + buttons and colour dots on the photo; floating cart chips (A/B/C) and the search + scan pill dock above the bottom bar. Tap a card → product page; + → cart count.
- **Product page** — customer view: full-bleed photo, colour swatch strip, code · name · price in Cormorant, cart stepper. Toggle *Salesperson view* for the stock / reserved / in-production / due-date matrix and staff tags.
- **Approvals** — one transaction per card: customer scores, tier appetite, order lines with photo + qty steppers, Reject / Approve.

Bottom bar (glass pill, maroon capsule) switches modules in every phone. Built from research/brd-final.txt (Catalogue, Home › Approvals) and the Miro wireframes for functionality; the user's Grok mockups for tone.
