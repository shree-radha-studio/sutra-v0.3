Pill-shaped action button; primary is the brand maroon and should appear once per view.

```jsx
<Button icon="package" caps iconRight="chevron-right">Pack</Button>
<Button variant="secondary">Add line</Button>
<Button variant="success" block>Confirm → Push to Busy</Button>
```

Variants: primary · secondary · soft · ghost · danger · success · inverse. Sizes sm 32 / md 40 / lg 48. `caps` for floor commands.
