Sutra · design board

One page per module, three views: New drafts (screens in planning), Finals (signed off) and Compare (both side by side). Phone beside web, every screen as a light + dark pair. Frames load as you pan. The old Catalogue explorations live in their own archive tab.

How the board works

  • Open a module: board.html?m=<id>. One frame: &only=n-3&z=0.8 (ids n- nd- nw- nwd- count within the page; f- fd- w- wd- are the finals and never change). &bare drops the device frame. &dev loads the React development build for readable errors.
  • Add a module: create mod-<id>.jsx, register from its end with window.NEW_DRAFT_MODULES.push({…}), add one line to modules.js. Never edit index.html or board.html.
  • Sign off: append the screens to FIN / WEB in finals.jsx and add a BOARD entry carrying the module id.
  • Share: commit and push; GitHub Pages serves this hub. Pull before you draw.
