# Design system: source of truth

The Sutra design system is edited **only** in Claude Design:

https://claude.ai/design/p/58929ba8-c7ab-4dc3-8c48-dcbb6f70704e

`design-system/` in this folder is a **read-only snapshot** of that project. Rules:

1. Nothing under `design-system/` is edited here. Claude Code reads it; it does not write to it.
2. Change the design in Claude Design, then export: **Share → Project HTML → Project archive → Export**. The zip lands in `~/Downloads/Sutra Design System.zip`.
3. Replace the snapshot with one command (wipes and re-copies, updates the stamp below):

```bash
bash tools/refresh-design-system.sh
```

4. App code lives outside `design-system/` and consumes its tokens, so a refresh never overwrites our work.
5. When implementation starts and the tokens stabilise, flip ownership: the repo becomes the source of truth and Claude Design is used only for new explorations.

## The current design language

Since 5 Sep 2026 the language every new screen follows is the one of the Final rows on the catalogue board. It is
written down in `design/SUTRA-DESIGN-SCHEMA.md` with tokens in `design/tokens-final.css`, and packaged for Claude
Design in `explorations/catalogue-v2/for-claude-design/design-system-update/`. Until that update is uploaded and
adopted in Claude Design, the schema file in this folder is the authority for new mockups; the snapshot below stays
the source for assets, research and the original component set. The workflow for new module mockups is the project
skill `.claude/skills/sutra-mockups`.

## What the snapshot contains

- `tokens/` – colour, type, spacing, radii tokens
- `components/` – core, forms, feedback, navigation, catalogue (incl. PriceText: leading digit +5% on customer-facing prices)
- `guidelines/` – screen inventory (every BRD screen, phone + web), voice, brand rules
- `research/` – extracted BRD text (`brd-final.txt`, `brd-masters.txt`)
- `ui_kits/` – `sutra-mobile`, `sutra-web`, `catalogue-explorations` (1a Gallery / 1b Atelier)
- `assets/` – logo, client lockups, sample product photos
- `uploads/` – original source docs and screenshots given to Claude Design
- `SKILL.md`, `readme.md`, `_ds_manifest.json`, `_ds_bundle.js` – generated by Claude Design
