# Sutra design system

The system lives in `design-system/` at the repository root. Read `design-system/readme.md` first (voice, casing, numbers, visual foundations, components), then open what the task needs: `tokens/`, `components/`, `ui_kits/`, `guidelines/`, `assets/`. The final design language every new screen follows is `design/SUTRA-DESIGN-SCHEMA.md` with `design/tokens-final.css`.

Non-negotiables: sand canvas (never white or grey), espresso ink (never black), one maroon line per screen (tab underline, nav bar or primary button), photo beside every design number, the design number is the head, Cormorant Garamond for display and Jost for UI, Lucide icons only, no emoji, sentence case, Indian number grouping, money only where the BRD allows.

For visual artifacts (slides, mocks, throwaway prototypes) copy assets out and produce static HTML the user can open. For production code, copy assets and follow the rules here.
